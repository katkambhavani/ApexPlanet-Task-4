# BookNest — Online Bookstore

## 1. Project Overview
BookNest is a responsive, full-stack online bookstore built with HTML, CSS, JavaScript, Bootstrap 5, PHP, and MySQL.

## 2. Objective
Build a functional web application with customer authentication, book management, order management, and an admin dashboard.

## 3. User Roles
- Customer: Register, log in, browse books, search and filter books, manage a shopping cart, place orders, and view order history.
- Administrator: Log in securely, manage books, manage users, manage orders, and view dashboard statistics.

## 4. Customer Features
- Home page and book catalogue
- Search, category filters, and pagination
- Registration, login, logout, and password recovery flow
- Book details and shopping cart
- Checkout and order placement
- Order history and order status

## 5. Admin Features
- Dashboard with statistics
- Create, read, update, and delete books
- View and manage users
- View and update orders
- Search, filtering, and pagination
- Analytics for orders and active users

## 6. Database
MySQL tables will cover users, roles, categories, books, orders, and order items, with appropriate primary keys, foreign keys, and indexes.

## 7. Security
- Hash passwords using PHP password_hash()
- Verify passwords using password_verify()
- Use prepared SQL statements
- Validate input on the server
- Protect admin routes and sessions
- Validate uploaded files if book images are supported
- Use CSRF protection for state-changing forms

## 8. Design System
- Primary: #172554
- Background: #FFF9F0
- Accent: #F59E0B
- Success: #15803D
- Font: Inter
- Responsive layouts with reusable CSS variables in assets/css/theme.css

## 9. Technology Stack
HTML5, CSS3, JavaScript, Bootstrap 5, PHP, MySQL, XAMPP, Git, GitHub, and Chart.js.

## 10. Deliverables
- Functional real-world web application
- Admin panel and CRUD functionality
