# BookNest – Online Bookstore

BookNest is a PHP and MySQL-based online bookstore developed as part of the **ApexPlanet Software Pvt. Ltd. Full Stack Web Development Internship – Task 4**.

The platform allows users to explore books, search and filter the collection, add books to a shopping cart, and manage their orders. It also includes an admin panel for managing books, users, and orders.

## Features

### Customer Features
- User registration and login
- Browse available books
- Search books by title or keyword
- Filter books by category
- View individual book details
- Add books to the shopping cart
- Checkout and order management
- View dashboard and order history

### Admin Features
- Admin dashboard
- Manage books (add, edit, and delete)
- Manage categories and store information
- View and manage customer orders
- View registered users

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP

## Installation and Setup

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside `C:\xampp\htdocs\`.
4. Open phpMyAdmin at `http://localhost/phpmyadmin/`.
5. Create a database named `booknest_db`.
6. Import `database/schema.sql`.
7. Check the database settings in `config/database.php`.
8. Open `http://localhost/ApexPlanet-Task-4/` in your browser.
